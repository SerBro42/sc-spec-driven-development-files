# Tech Stack

We will use a TypeScript-first server-side stack built for speed, clarity, and maintainability.

## Recommended stack

- TypeScript for application logic and type safety.
- Hono as the server-side framework for a lightweight, modern TypeScript web app.
- SQLite as the database for local, reliable persistence of agents, ailments, therapies, and appointments.
- HTML/CSS/JavaScript delivered through a modern browser-friendly UI for a polished, responsive experience.
- A simple app structure that supports fast iteration while staying easy to explain in demos and course materials.

## Why this stack

- TypeScript gives us a popular, familiar language for engineering teams and AI coding workflows.
- Hono is a lightweight framework well suited to server-side TypeScript and straightforward app logic.
- SQLite fits the product needs for a simple, reliable data store without unnecessary operational complexity.
- The stack remains approachable for students and conference demos while still being production-ready enough for a real product foundation.
